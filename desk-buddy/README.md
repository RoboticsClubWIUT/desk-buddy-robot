# Desk Buddy: робот с эмоциями на ESP32

Маленький настольный робот: глаза на OLED-экране, реагирует на касание, показывает время.

| Действие | Реакция |
|---|---|
| Нет касаний 30 секунд | засыпает |
| Касание | просыпается и смеётся |
| Держим палец ~1 секунду | показывает время на 5 секунд |

## Лестница: от простого к сложному

Делай по порядку и не переходи дальше, пока текущий шаг не работает.

| Шаг | Папка | Что проверяем |
|---|---|---|
| 1 | `01_touch_sensor` | датчик касания пишет "Touched" в Serial Monitor |
| 2 | `02_oled_emotions_4pin_i2c` или `02_oled_emotions_7pin_spi` | экран показывает эмоции (радость, грусть, злость) |
| 3 | `03_final_4pin_i2c` или `03_final_7pin_spi` | всё вместе: касание + эмоции + часы |

Выбери папку по своему экрану: **4 pin** (I2C) или **7 pin** (SPI).

## Детали

- ESP32-C3 Super Mini
- Датчик касания TTP223
- OLED 128x64 (SSD1306): 4 pin (I2C) или 7 pin (SPI)
- Провода (пайка не нужна, если на плате уже стоят пины)

ESP32 работает от **3,3 В**. Всё питание берём с пина **3V3**, не с 5V. GND и 3V3 общие для всех деталей.

## Подключение

**Датчик касания (для всех шагов):**

| Датчик | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| I/O | GPIO 1 |

**OLED 4 pin (I2C):**

| OLED | ESP32 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SDA | GPIO 5 |
| SCL | GPIO 6 |

**OLED 7 pin (SPI):**

| OLED | ESP32 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| D0 (SCK) | GPIO 4 |
| D1 (MOSI) | GPIO 6 |
| RES | GPIO 10 |
| DC | GPIO 3 |
| CS | GPIO 7 |

Не используй GPIO 8 и 9 (они нужны для загрузки платы).

## Настройка Arduino IDE

1. В Boards Manager установи **esp32 by Espressif Systems**.
2. Tools → Board → **ESP32C3 Dev Module**.
3. Tools → **USB CDC On Boot → Enabled** (иначе не будет Serial Monitor).
4. Если загрузка не идёт: зажми кнопку **BOOT**, подключи USB и загрузи снова.
5. В Library Manager установи: **Adafruit GFX Library**, **Adafruit SSD1306**, **FluxGarage RoboEyes**.
6. Serial Monitor: скорость **115200**.

## Часы (Wi-Fi)

В финальном шаге робот берёт точное время из интернета (NTP) при включении, потом считает сам.

- Впиши `WIFI_NAME` и `WIFI_PASS` в скетче.
- Нужен Wi-Fi **2.4 GHz** (точка доступа с телефона подходит).
- Часовой пояс: `5 * 3600` это UTC+5 (Ташкент). Поменяй цифру 5 для другого пояса.
- **Не коммить настоящий пароль в GitHub.** В репозитории оставляй `YOUR_WIFI` и `YOUR_PASSWORD`.

## Если не работает

| Проблема | Что проверить |
|---|---|
| Пустой экран (4 pin) | SDA и SCL не перепутаны; адрес `0x3C` (попробуй `0x3D`) |
| Пустой экран (7 pin) | провода на пинах из таблицы; D0 и D1 не перепутаны |
| Сдвинутая картинка на экране 1,3" | у него чип SH1106, нужна другая библиотека (U8g2) |
| Вместо времени `--:--` | Wi-Fi не подключился; раскомментируй строку `WiFi.setTxPower(WIFI_POWER_8_5dBm);` |
| Время неправильное на часы | поменяй часовой пояс (`5 * 3600`) |
| Нет текста в Serial Monitor | включи USB CDC On Boot, скорость 115200 |
